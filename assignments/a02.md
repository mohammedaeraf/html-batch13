## Assignment: Create a Services Section

Create a **Services** section below the About section of your Bootstrap website.

### Requirements

- Add a section with the ID `services`.
- Give the section a suitable heading such as **Our Services** and a short introductory paragraph.
- Create a row of **three Bootstrap cards** arranged responsively:
  - Use `container`, `row`, and `col-*` classes.
  - Display three cards on medium and larger screens.
  - Stack the cards vertically on small screens.
- Each card should include:
  - A relevant icon or image.
  - A service title.
  - A short description.
  - A Bootstrap button labeled appropriately.
- Use the `card`, `card-body`, `card-title`, and `card-text` classes.
- Use Bootstrap spacing and shadow utility classes such as `p-4`, `mb-3`, and `shadow-sm`.
- Apply equal card heights using `h-100`.

### Example Structure

```html
<section class="py-5" id="services">
  <div class="container">
    <h2 class="text-center mb-3">Our Services</h2>
    <p class="text-center mb-5">
      Explore the services we offer.
    </p>

    <div class="row g-4">
      <div class="col-md-4">
        <div class="card h-100 shadow-sm">
          <div class="card-body">
            <h5 class="card-title">Service Title</h5>
            <p class="card-text">Service description...</p>
            <a href="#" class="btn btn-primary">Learn More</a>
          </div>
        </div>
      </div>
    </div>
  </div>
</section>
```

### Submission

Place the Services section directly below the About section and submit the updated HTML file. Your final section should be visually consistent with the rest of the website.
