# 📝 JavaScript Assignment – DOM Manipulation

**Objective:** Learn how to use JavaScript to access and manipulate HTML elements dynamically.

### Assignment: Interactive Heading Changer

Create an HTML page with the following elements:

1. An `<h1>` heading displaying **"Welcome to JavaScript"**.
2. An `<h2>` heading displaying **"Learning DOM Manipulation"** with an ID of `heading2`.
3. A paragraph displaying **"Click the button below to change the heading."**
4. A button labelled **"Change Heading"**.

### JavaScript Requirements

Write a JavaScript function named `changeHeading()` that performs the following operations when the button is clicked:

1. Access the `<h2>` element using `document.getElementById()`.
2. Change its text colour:
   - If the current colour is blue, change it to orange.
   - Otherwise, change it to blue.
3. Change the heading text to **"JavaScript Changed This Heading!"**.
4. Make the heading bold.
5. Add an underline to the heading.
6. Add a `2px solid green` border around the heading.
7. Change the paragraph text to **"You have successfully manipulated the DOM using JavaScript!"**.

### ⭐ Bonus Tasks

Try implementing the following additional operations:

1. Hide the `<h1>` heading using `style.display`.
2. Change the background colour of the paragraph.
3. Increase the font size of the `<h2>` heading to `30px`.
4. Change the button text to **"Heading Changed!"** after clicking it.

### 📌 Submission Instructions

- Create a file named `dom-assignment.html`.
- Write your HTML and JavaScript in the same file.
- Test all the required functionalities in your browser.
- Submit the HTML file.

**Learning Outcome:** Understand how JavaScript interacts with HTML elements using DOM methods and modifies their content and CSS styles dynamically.
